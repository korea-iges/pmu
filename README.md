# PMU 펌웨어 업그레이드 파일

- 이 디렉터리에는 업그레이드에 사용하는 펌웨어 파일만 보관

## 디렉터리

- `app/[버전]/`: PMU 앱 업그레이드 파일
- `bootloader/[버전]/`: 부트로더 업그레이드 파일
- `PMUtool/[버전]/`: PMU 설정·관리 도구 exe
- `PMUFactoryTool/[버전]/`: 생산 도구 exe
- `OLDPMUinfo/[버전]/`: 구형 PMU 정보 수집 도구 exe (현장 장치 교체용)
